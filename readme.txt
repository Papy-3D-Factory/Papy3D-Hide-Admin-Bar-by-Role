Control WordPress admin toolbar visibility on the front end for selected user roles.

== Description ==

RoleBound Admin Toolbar lets administrators choose which user roles should not see the WordPress admin toolbar on the front end.

The toolbar remains available inside the WordPress dashboard.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install it from the WordPress plugin installer.
2. Activate the plugin through the Plugins screen in WordPress.
3. Go to Settings > RoleBound Toolbar.
4. Select the roles for which the front-end admin toolbar should be hidden.

== Frequently Asked Questions ==

= Does this remove access to the WordPress dashboard? =

No. It only controls the admin toolbar visibility on the front end.

= Does it affect logged-out visitors? =

No. WordPress does not display the admin toolbar to logged-out visitors.
