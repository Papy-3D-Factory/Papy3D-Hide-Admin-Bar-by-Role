Hide the WordPress admin bar on the front end for selected user roles.

== Description ==

Hide Admin Bar allows administrators to disable the WordPress admin toolbar on the front end for specific user roles.

Features:

* Hide admin bar by user role
* Simple settings page
* Lightweight plugin
* No dependencies
* Works on the front end only
* Keeps the admin bar visible inside wp-admin

Perfect for membership websites, client sites, and custom user experiences.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to `Settings > Hide Admin Bar`
4. Select the user roles you want to hide the admin bar for
5. Save changes

== Frequently Asked Questions ==

= Does this hide the admin bar in wp-admin? =

No. The admin bar is only hidden on the front end of the website.

= Can I hide the admin bar for administrators? =

Yes. You can select any registered user role.

= Does this plugin affect logged out users? =

No. Logged out users already do not see the admin bar.
